Quick Start

Get better performance or graphics in about five minutes. This assumes the app is installed and you're on the Home screen.

  1. Connect. Tap the method chip on the Home screen until it shows ADB or Shizuku, then tap Connect. Wireless Debugging users: the app auto-scans ports 37000–44000.
  2. Analyze. Open Config Generator → Analyze Device. The app reads the game's Client.log and extracts your GPU, RAM, FPS, and thermal data.
  3. Generate & deploy. SmartBrain picks a preset — tap Generate, review, then Deploy to Device.
  4. Compare. After playing, open Deploy History → your deploy → Compare Now to see the FPS / thermal / OOM difference.

Connecting to Your Device

The app reads and writes the game config folder at:

/storage/emulated/0/Android/data/com.kurogame.wutheringwaves.global/files/UE4Game/Client/Client/Saved/Config/Android/

Tap the method chip on the Home screen to cycle ADB → Shizuku → Root → SAF.

ADB (Wireless Debugging) — recommended

  1. Enable Developer Options → Wireless Debugging on your phone.
  2. Tap Wireless Debugging → Pair device with pairing code the first time.
  3. In the app, tap Connect — it scans ports 37000–44000. Accept the RSA prompt on your phone.

Prefer a PC? Run adb tcpip 5555 then adb connect 192.168.x.x:5555, then Connect in the app — it finds port 5555 automatically.

Shizuku

  1. Install Shizuku and start its service.
  2. Cycle to Shizuku in the app, tap Permit → Connect.

Root

  1. Cycle to Root, tap Test Root, grant superuser in your root manager, then Connect.

SAF (Storage Access Framework)

Best for quick edits. Tap Pick Dir and select the game's Config/Android folder. SAF has no shell access, so config generation and log reading are limited.

Home Screen

Backend status

  • Chip — tap to cycle connection methods.
  • Connect / Disconnect — establish or drop the session.
  • State — green = connected, gray = disconnected.

Quick actions

  1. Profile — player UID, server, level, tower, version.
  2. Battle Stats — combat telemetry parsed from Client.log.
  3. Pity Tracker — gacha history and pity predictions.
  4. Backups — saved config snapshots with per-file restore.
  5. Collect Client.log — saves the game log to Downloads/WuWaConfig/Client.log.
  6. Config Generator — full optimization UI.
  7. INI Editor — edit the 5 monitored INI files on-device.
  8. App Log — full log viewer with search/filter.

Clean Config Files (red button) strips CVar values while keeping [Core.System] paths, or deletes selected INI files entirely.

Every time you connect, the app auto-checks all 5 INI MD5s against the game's hash file and fixes any mismatch before you do anything.

Config Generator

The core feature: analyze your device, tune settings, and deploy optimized configs.

Analyze

  • Analyze Device — copies Client.log locally (handles 100MB+ files) and parses it. Shows GPU, RAM, FPS, thermal events, OOMs, and active CVars.
  • Import Log — pick a saved .log for offline analysis.

SmartBrain scoring

SmartBrain scores your device 0–100 from GPU tier, RAM, FPS, thermal, OOM, render scale, and more, then recommends a preset. Scores ≥85 point at Cinematic/Ultra; ≤20 drop to Potato. After a deploy you can compare results in Deploy History.

Tuning options

  • Advanced per-device tuning — replaces the fixed preset with CvarOptimizer, computing each CVar from your GPU tier, RAM, thermal events, and OOM counts.
  • CVar optimization — comments out CVars matching game defaults (; REDUNDANT) and flags unknown ones (; UNKNOWN CVar).
  • Frame target — 30 / 45 / 60 / 90 / 120 FPS.
  • Graphics options — 120 FPS unlock, ultra quality unlock, VSync, auto cooling, Vulkan safety CVars, and effect toggles (fog, chromatic aberration, toon outlines, bloom, auto exposure, SSR, and more).

Generate & deploy

  1. Configure options, tap Generate.
  2. The ReviewTune screen opens — review and edit the generated text.
  3. Tap Deploy to Device — pushes files and refreshes the game's hash file.
  4. Tap Verify to cross-reference deployed CVars against Client.log.

Backups & Restore

  • Create — name a backup, pick which of the 5 INIs to include, Create.
  • Restore — choose files (all checked by default) and Restore.
  • Auto-backup — when on, custom config deploys are backed up first (all 5, or only overwritten files if fewer were uploaded).
  • Delete — remove any backup card.

Pity Tracker

  1. Open Convene History in-game at least once.
  2. Tap Fetch Gacha History — the app finds the Convene URL in Client.log and pulls from Kuro's API.
  3. Results show total pulls, ★5/★4 counts, average pity, per-pool breakdown, and predictions.

If the URL isn't found, use Poll in Background — it polls every 10s (up to 30 tries) and notifies you when found. Results are cached locally for 12 hours.

Player Profile

Read-only. Extracts UID, server, level, tower floor, weekly rogue score, battle pass status, version, language, last login, and a config summary chart from LocalStorage.db, DeviceStorage.db, and .sav files. Tap Refresh to re-fetch.

Deploy History

Every deploy saves a record. Tap Compare Now to read fresh Client.log and compute deltas (FPS, thermal, OOM, frame drops) — green = improvement, red = regression.

If a record used Advanced tuning, a Retune & Deploy button appears that auto-adjusts settings based on the deltas and re-deploys until stable.

Up to 20 records are kept; clear all from the top of the list.

Config Generation Deep Dive

The 5 INI files

FilePurpose
Engine.iniCVar settings (graphics, performance, shadows, AA, …)
DeviceProfiles.iniPer-SoC GPU profiles and CVars
GameUserSettings.iniResolution, VSync, FPS cap, scalability
Scalability.iniResolution quality, view distance, quality levels
Hardware.iniHardware profile, frame pacing, Anisotropy, mip bias

DeviceProfiles

Detects your SoC (40+ profiles, Adreno 830 down to Mali-G57) and applies device-specific profiles; falls back to universal preset-based profiles.

CVar optimization

  1. Import CVars from log
  2. Apply your overrides
  3. Comment out redundant/unknown CVars
  4. Deduplicate (last wins)
  5. Strip 31 Kuro-restricted (forbidden) CVars

File push

  1. Content base64-encoded and split into printf '%s' chunks (~4000 bytes)
  2. Written to /data/local/tmp, decoded via base64 -d
  3. MD5 verified against the local source; retried on failure

In-App Updates

Update the app without a PC from Settings → Check for updates.

  1. Tap Check for updates — queries the latest GitHub release.
  2. If a newer version exists, a card shows the version, notes, and a Download button.
  3. The APK downloads (with progress). Before installing, the app verifies the downloaded APK's signing certificate matches the installed app's — only then does it open the system installer.

The update only installs APKs signed by the same key as your installed app, protecting you from tampered builds. If you sideloaded a debug build, release updates will be refused — reinstall the official release to update.

FAQ & Troubleshooting

"Cannot connect via ADB" — enable Wireless Debugging, same network, restart it, or enter the IP:port manually.

"Client.log too large" — the app copies it locally and parses there; all backends supported.

"No Convene URL found" — open Convene History in-game first, or use Poll in Background.

"Config deploy failed" — check the game directory exists, ensure write access, try another method.

"Update refused — signature mismatch" — debug build vs release build; reinstall the official release APK.
