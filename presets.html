05 / Engine.ini Output

~350 CVars, Topic by Topic

Each generation writes Engine.ini, DeviceProfiles.ini, GameUserSettings.ini, Scalability.ini and Hardware.ini — tailored to your device and preset. Engine.ini is grouped into commented blocks (character quality, AA, post-processing, shadows, streaming, LOD, thermals…), and Scalability.ini carries the four quality tiers.

E.01

Character Quality

SkeletalMesh LOD scale, outlines, face shadows, eye distance, rim light, auto-exposure, radial blur, landscape capture.

E.02

Scalability

sg. quality levels — shadow, texture, post-process, effects, AA, view distance, foliage.

E.03

Anti-Aliasing

PostProcessAA=6, TAA upsampling, Catmull-Rom filtering, mobile frame weights.

E.04

Post Processing

Bloom 0–4, eye adaptation, MotionBlur=0, depth of field, light shaft, LensFlare=0, CA, tonemapper, upscale.

E.05

Shadow

Point light shadows, CSM cascades, radius thresholds, per-object resolution, mobile dynamic point lights (2), single-pass.

E.06

Texture Streaming

MipBias, LODBias, MaxAnisotropy 4–16, PoolSizeMode, KuroMinFOVFactor.

E.07

Mobile Rendering

ShadingPath=1, FSR upscale, MSAA=0, HBAO, pixel-projected reflections, static + CSM shadow receivers.

E.08

VRS

Variable Rate Shading — Material + Mesh VRS enabled where the GPU benefits.

E.09

Effects / Particles

GPU particle caps, Niagara quality tiers, spawn-rate scaling, max CPU/GPU particles.

E.10

Water / Reflection

WaterSSR, SSR, SceneObjSSR, planar reflection, half-res SSR, roughness response.

E.11

Environment

Fog, volume clouds, light functions, ISM draw distances, grass culling, foliage/grass density, LOD distance.

E.12

LOD / Culling

Clustered deferred, HZB occlusion queries, min/max screen radius, StaticMeshLODDistanceScale, parallel frustum cull.

E.13

Animation

URO (Update Rate Optimization) enabled, forced animation rate on budget devices.

E.14

Frame & Display

MobileHDR, VSync, FramePace cap, SkinCache memory, ShaderPipelineCache, PSOCache.

E.15

Pipeline / RHI

PSO cache eviction, RHICmd bypass + parallel + threading, async RHI dispatch.

E.16

Thermal & Stability

AutoCool, thermal control mode, Vulkan robust buffer access for crash-prone drivers.

06 / CVar Database

5,889 CVars, Fully Classified

Three-level matching classifies every CVar the game can expose: 52 exact overrides, then 200+ r. sub-rules, then 18 top-level prefixes. On top of that, the CVar database knows which settings your device can never use — and comments them out instead of shipping them.

Dead-on-your-device CVars
Graphics-API families that don't apply to your device are commented out — the r.Vulkan.* family on an OpenGL ES device, and vice versaauto-detected
Console, PC and Metal-only variants (r.PS4.*, r.Metal.*, _PC suffixes) — verified against exact tokens, so the Android-valid r.PSO.* family is never caughtsafe by design
Each is prefixed with a marker instead of being deleted, so one character restores it1 char to undo
Engine generation detection
Reads the ++UE4+… / ++UE5+… build banner out of Client.log instead of assuminglog-driven
UE5-only CVars are suppressed on a UE4 build — the game ignores them anyway, so shipping them is just noiseUE4 / UE5
Re-evaluated on every generation, so switching graphics API in-game brings its family straight backno sticky state
