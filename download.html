08 / Access Methods

Rooted or Stock — You're Covered

ADB Wireless Recommended Full Access

Native in-app ADB wire protocol — no external binary. Full RSA 2048-bit auth handshake (SHA1withRSA, SSH-RSA pubkey), Android 11+ wireless pairing with the code from Developer options, auto port scanning and MD5-verified chunked pushes.

Ports 37,000–44,000 + 5555Wireless pairing (Android 11+)Loopback checked firstRSA 204815s keepaliveKeys sealed by the hardware KeyStore

Shizuku Best Non-Root No Root Needed

Binder-based UserService with graceful fallbacks and automatic temp-file cleanup. No compile-time dependency on the Shizuku API. If the bind stalls on a Chinese ROM, an in-app walkthrough points you at the exact settings to change.

Root Full Access

Direct su -c shell via Magisk, KernelSU or APatch. No chunking needed — straight file operations with exit-code verification.

SAF Read / Write Only

Storage Access Framework via DocumentFile with a persistable tree URI and 3-strategy path resolution. No shell — safest option.

11 / Tech & Deploy

Under the Hood

How deployment stays safe, and what the app is built with.

Deploy pipeline
SNAPSHOT HASHES→AUTO-BACKUP→PUSH (RETRY ×2)→RECONCILE HASHES→VERIFY LOG

Your game's 70+ [Core.System] paths are read off the device and re-applied, so plugin content keeps resolving. Files go via a staging directory with retry and are only reported as deployed once the whole pipeline finishes — a hash-sync or verification failure is a failure, not a warning.

Deploy safety system
D.01

Hash Sync

KuroConfigMonitor snapshots hashes before deploy and reconciles after — concurrent game access is detected. ModifyCount capped at 8; atomic .new → rename push with read-back verification.

D.02

Deploy History

deploy_history.json stores up to 20 records: preset, method, files, accepted / redundant / unknown counts, plus baseline & outcome metrics (FPS, thermal, OOM, drops) for delta comparison.

D.03

One-Tap Retune

Every deploy history entry keeps the settings it shipped with, so you can redeploy it adjusted — never an automated loop. Stable (±5 FPS, no OOM): keep. Degraded: screen ×0.75, shadow −2, detail −1, reflections and draw distance cut. New OOM: back to the Potato baseline. Improved: screen ×1.15, shadow +1.
