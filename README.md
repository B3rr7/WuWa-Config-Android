| 🔧 **CVarDB 5,885 Entries** | `optimizeIniText()` comments redundant/unknown with `; [CvarDB]`. `ForbiddenCvars` (31) stripping. `CvarCategorizer` 3-level match, 18 categories |

### 🔧 Quick Troubleshooting Reference

| Symptom | Fix | Preset |
|---|---|---|
| FPS drops below target | Lower Screen% to 60–80%, Shadow 0–2, check `r.FramePace.MaxFPS` | Balanced / Competitive |
| Thermal throttling | `ReflectionEnvironment=0`, all dynamic lights=0, disable volumetric fog, `AutoCool` ON | Potato / Endurance |
| GPU OOM out of memory | `Shadow MaxResolution`→1024, `Anisotropy`→4, `PoolSize`→512, disable HD packs | Potato |
| Missing / broken textures | Enable `r.HZBOcclusion=1`, `MipMapLodBias`→0–1, raise `PoolSize`, verify DeviceProfile | Any + HZB |
| Stuttering / uneven pacing | Lower render scale if CPU-bound, disable VSync, enable `RHICmd` bypass, set `MaxFPS`=60/120 | Any + RHICmd |
| Exynos / Mali underperforming | Start one tier below Snapdragon equivalent, lower shadow & streaming | Competitive / Balanced |
| 120 FPS not unlocking | Enable 120 FPS toggle, check `r.FramePace.MaxFPS=120`, ensure thermal headroom | Flagships only |
| Post-processing artifacts | `PostProcessQuality`→0–2, `Bloom`→0–1, disable auto-exposure, reduce radial blur | Competitive+ |
| Slow deploy / Permission denied | Use `run-as` fallback (Shizuku/ADB), switch to SAF for scoped storage, Root | N/A |

## ⚡ Quick Start

### For Players (Install APK)

```bash
# 1. Download latest APK
open https://github.com/B3rr7/WuWa-Config-Android/releases

# 2. Install on Android 8.0+ (allow "Install unknown apps")
# 3. Open → Accept Terms → Grant Storage permission → Connect (see Access Methods)
```

### For Developers (Build from Source)

```bash
# Prerequisites: JDK 17, Android SDK 34, Git
git clone https://github.com/B3rr7/WuWa-Config-Android.git
cd WuWa-Config-Android

# Lint (style is load-bearing — CI gates on ktlint)
./gradlew ktlintCheck          # check
./gradlew ktlintFormat         # auto-fix

# Tests (JUnit 4 + Mockito, 14 pure-logic files, no instrumentation)
./gradlew testDebugUnitTest
./gradlew testDebugUnitTest --tests "com.wuwaconfig.app.config.CvarCategorizerTest"
./gradlew testDebugUnitTest --tests "com.wuwaconfig.app.config.*"

# Build APKs
./gradlew assembleDebug        # → app/build/outputs/apk/debug/WuWaConfig-debug.apk (offline)
./gradlew assembleRelease      # → WuWaConfig-v1.1.5-release.apk (needs keystore.properties + network once for lint-gradle:31.4.2)

# Install to device
adb install -r app/build/outputs/apk/debug/WuWaConfig-debug.apk

# Clean build
./gradlew clean assembleDebug
```

### One-Line Verification

```bash
./gradlew ktlintCheck && ./gradlew testDebugUnitTest && ./gradlew assembleDebug
```

> APK names are hardcoded in `app/build.gradle.kts`: debug `WuWaConfig-debug.apk`, release `WuWaConfig-v{versionName}-release.apk`. Root `WuWaConfig-debug.apk` is a stale manual copy — rebuild.

## ✨ Feature Breakdown

### 1. FPS Booster & Config Generator (8 Presets + SmartBrain)

`config/ConfigGenerator.kt: generateWithCorePaths()` builds 5 INIs, merges log CVars, runs `CvarDatabase.optimizeIniText()` (`; [CvarDB] <reason>`), strips `ForbiddenCvars` when `allowRestrictedCvars==false`.

| Preset | Detail | Screen% | Shadow | ShadowRes | SSR | MipBias | Streaming | ViewDist | Foliage LOD | LOD Bias | GrassCull |
|--------|--------|---------|--------|-----------|-----|---------|-----------|----------|-------------|----------|-----------|
| **POTATO** | 0 | 50% | 0 | 128 | 0 | 3 | 0.3× | 0.3 | 0.4 | 5 | 1,500 |
| **ENDURANCE** | 1 | 55% | 0 | 128 | 0 | 3 | 0.4× | 0.4 | 0.5 | 4 | 2,500 |
| **PERFORMANCE** | 2 | 60% | 0 | 256 | 0 | 3 | 0.5× | 0.5 | 0.6 | 3 | 4,500 |
| **COMPETITIVE** | 3 | 100% | 0 | 256 | 0 | 1 | 1.0× | 2.0 | 1.0 | 1 | 2,000 |
| **BALANCED** | 4 | 80% | 2 | 1,024 | 1 | 0 | 2.0× | 1.5 | 2.0 | 0 | 15,000 |
| **HIGH** | 5 | 100% | 4 | 2,048 | 2 | 0 | 3.0× | 2.0 | 2.5 | 0 | 20,000 |
| **ULTRA** | 6 | 100% | 5 | 2,048 | 4 | -1 | 4.0× | 3.0 | 3.0 | -1 | 30,000 |
| **CINEMATIC** | 7 | 100% | 5 | 4,096 | 4 | -2 | 6.0× | 4.0 | 4.0 | -2 | 40,000 |

*Tier-scoped quality fields:* `characterDetail` (0–3 → `r.KuroMaterialQualityLevel`), `postProcess` (0–3 → `sg.PostProcessQuality`), `staticLighting` (bool → `r.AllowStaticLighting`), `cutsceneQuality` (0–3 → `r.Kuro.Movie.EnableCGMovieRendering`). `vulkan`/force-OpenGL is a **global** `GeneratorOptions` toggle (not tiered) — deliberately avoids broken combos. Potato/Performance add HZB forced on, `ReflectionEnvironment=0`, `DistanceFieldShadowing=0`, aggressive LOD culling. See `docs/CONFIG-GENERATOR.md`.

**Options:** 120 FPS unlock, Ultra quality unlock, VSync, Auto cooling, Force Vulkan, HZB occlusion, Disable fog/CA/outlines/blur/bloom/auto-exposure/SSR, Hardware.ini (`ChipsetDetector`), GameMode `Overworld` / `ToA` (Tower of Adversity).

**Generate → ReviewTune:** monospace editor (`IniEditorScreen` + `LineDiff`/`Hashing.md5Of`), per-file toggle, edit inline, deploy or close. `FullscreenMode=0` avoids Android windowed bottom-left viewport bug; `KuroRenderQuality@0..@3` in Scalability.

### 2. SmartBrain Device Scoring (0–100)

`config/SmartBrain.kt` + `CvarOptimizer.kt` — ~20 signals → `recommendPreset()` (first-match wins top-to-bottom):

| Signal | Impact |
|--------|--------|
| GPU tier (Snapdragon/Adreno, Dimensity/Mali, Exynos, Tensor via `ChipsetDetector`) | +30 to -20 |
| RAM | +8 to -15 |
| Vulkan | +8 |
| FPS drops / frame drops | -6 to -18 / -5 to -10 |
| Thermal throttling | -5 to -20 |
| GPU OOM (`gpuOom ≥2` → `potato`) | -12 to -30 |
| Auto-adjust triggers (>10) | endurance/performance path |
| Forbidden CVars (-5 each, toggleable) | -5 |
| Unknown CVars (>5) | -5 |
| Active CVars vs defaults | +5 or -8 |

**Preset routing:** `potato` if `gpuOom≥2` or low-mem or `≤20`; `cinematic` if `≥85`+Vulkan+flagship+no thermal; `ultra` `≥80`; `high` `≥75/70`+flagship; `competitive` `≥45`+`fpsCap-fpsActual>15`; `balanced` `≥40`; `endurance`/`performance` on thermal/auto-adjust. `HashMonitor`, `ProfileExtractor` (parallelized) and `ConfigGenUtil` feed signals.

### 3. CVar Database & Optimizer (5,889 Entries)

- **Source:** `assets/cvars/libUE4_cvars.txt` (5,889) + `config_monitor_cvars.txt` / `config_monitor_values.txt` (735 each); `*_categorized.txt` mirrors shipped for tooling, not loaded.
- **Runtime:** `CvarDatabase` loads 3 files async in `WuWaConfigApp.onCreate`; `optimizeIniText()` comments redundant/unknown with `; [CvarDB] <reason>` (single tag).
- **Categorization:** `CvarCategorizer` standalone `object`, 3-level matching, 18 categories, Android-free testable.
- **Safety:** `ForbiddenCvars` 31 entries; `stripForbiddenCvars()` when `allowRestrictedCvars==false`; `CvarCategorizerTest`, `CvarDatabaseOptimizeTest`, `ForbiddenCvarsTest` cover it. `LogParser` pre-compiles per-line `Regex` `val`s (hot path `parseLog` cognitive 118, 23 `linear_scan_in_loop` — already hoisted).

### 4. Gacha Pity Tracker (11 Pools, No Cap)

`config/GachaApi.kt` + `GachaHistoryStore` (`gacha_history.json`, 12h TTL) + `GachaViewModel` (cancellable) + `PityScreen`:

- **Fetch:** reads Convene URL from `Client.log` (auto-retries 6×10s — URL appears after opening Convene History in-game), `gmserver-api.aki-game2.com/net` (user-initiated, `network_security_config` allows cleartext only to `127.0.0.1`/`localhost`), 11 pools (Character Event, Weapon Event, Standard, Beginner 1/2 + 3 event rotations), **no truncation**.
- **Pity Overview:** Total Pulls · ★5 · ★4 + Avg ★5/★4 pity.
- **Next ★5 Prediction per pool:** status pill `Guaranteed` (gold) / `50/50` (amber), progress bar with soft-pity zone (amber from pull 66, dataset ~394K wuwatracker.com), `pullsSinceLastFive / hardPity (Soft 66 · Hard 80)`, soft-pity banner, last ★5 name+time, `"$subject is guaranteed/50/50"` (named per banner), 5 stat columns (`Since ★5`, `To Hard`, `Est. ★5`, `Since ★4`, `Est. ★4`), disclaimer *Simple estimate — not a guarantee*.
- **Histories:** grouped by pool, `★5×N`/`★4×N` badges, reverse order, `×count` for grouped 10-pulls; **Result History** cyan banner `N pulls · N★5 · expires in Hh` with Load/Clear.

### 5. Battle Stats Analyzer

`config/ProfileExtractor.readBattleStats` + `LogParser.parseBattleStatsLines` (Chinese battle-stats, cognitive 62) + `BattleStats` (`operator plus` fan-in 70 for parallel merge) + `BattleStatsStore` (`cached_battle_stats.json`, 24h) + `LogInsightsViewModel` + `BattleStatsScreen`:

- **100% coverage:** contiguous `dd` partition reads across cores, XOR-LUT decrypt (`LUT(LUT(b)) = b xor 0x4A`), UTF-16/8 auto-detect, per-partition parallel.
- **Global patterns:** battle counters, deaths, role changes, teleports, stamina, dodges, echoes, ultimates.
- **Cards:** Combat · Exploration · Economy · Social · System chips; cached 24h + Refresh.

### 6. Player Profile (Read-Only, Undetectable)

`ProfileExtractor.readProfile` + `ProfileStore` (`player_profile.json`, no TTL) + `ProfileViewModel` + `ProfileScreen`:

- UID, Server, Level header; Game Progress (Tower floor, Weekly Rogue, Battle Pass); Game Info (version, language, device ID, last login); Config bars (Engine/DeviceProfiles/GameUserSettings counts). Zero write footprint.

### 7. Backup, Restore & Hash Monitor

`config/BackupStore` + `HashMonitor` + `DeployHistoryStore` (`deploy_history.json`, 20 records) + `BackupViewModel` + `BackupScreen`/`HistoryScreen`:

- **Backups:** per-file checkboxes on create/restore, auto-backup before every write, also mirrored to `Downloads/WuWaConfig/Backups/{id}.json+.ini`; delete per-record or clear all.
- **Hash Monitor:** `KuroConfigMonitor.hash` MD5 sync via `refreshConfigHashes` (`ModifyCount` capped at 8, atomic `.new`+`mv`), `snapshotHashFile`/`reconcileAfterModify` guards concurrent game writes, `shared hashMutex` in `HashMonitor`. Auto-sync on connect fixes desync before actions.
- **Deploy Verification:** pulls fresh `Client.log`, `verifyDeployedCvars` vs `ConfigMonitor` CVars, accept/reject badge + tag chips (`N redundant`, `N unknown`, `N monitored` via `VerificationReport`).

### 8. INI Editor & Log Tools

- **INI Editor** (`IniEditorScreen` + `IniEditorViewModel` + `util/LineDiff`): full-screen monospace, `syncConfigHashes`, `pushSingleFile`, `Hashing.md5Of`, `findMatches` search, push+hash refresh on save, auto-syncs on open. `ReviewTuneScreen` (driven by `MainViewModel` `ReviewTune*` StateFlows) reviews `GeneratedIni` before deploy.
- **Logs** (`LogsScreen` + `LogRepository` fan-in 108): 1000 in-memory entries, 5MB rotate → `app.log` + `.1/.2` → `Downloads/WuWaConfig/logs/`, color-coded, `buildHighlightedMessage` (3 allocs/line), search/filter by `LogLevel`.
- **Custom Config** (`HomeScreen`): pick `.ini` files (match `Engine|DeviceProfiles|GameUserSettings|Scalability|Hardware`), Backup Scope dialog (<5 files), Success green check, `Clean Config Files` strips CVars preserving `[Core.System]` paths.

## 🔌 Access Methods (How to Connect)

App reads/writes `Android/data/com.kurogame.wutheringwaves.global/` — 4 backends via `backend/AccessBackend` (10 suspend ops) + `ShellUtils` (`shQuote` fan-in 44, `computeMd5`, `PUSH_RETRY_COUNT=2`, `MAX_ARG_STRLEN=4096`):

### ADB — In-App Wireless Debugging (No Root, No PC)

*Best for non-rooted users. App implements ADB wire protocol (`adb/AdbProtocol` 24-byte header, `AdbClient` TCP+auth handshake + 15s heartbeat + `drainTrailingWrite`, `AdbCrypto` RSA-2048 `EncryptedFile`+`AndroidKeyStore`, `PortScanner` 37000–44000+5555, `AdbConnectionService` foreground service).*

**Auto-connect (no PC):** Enable **Wireless Debugging** in Developer Options → **Connect** in app (auto-scans 37000–44000) → Accept RSA fingerprint. Android 16+ may need re-pair after reboot (auto key regen).

**With PC (USB Debugging ON):**

```bash
adb tcpip 5555
adb connect 192.168.x.x:5555
# Disable:
adb disconnect 192.168.x.x:5555
adb usb  # or reboot (clears TCP mode)
# Multi-device:
adb -s 192.168.x.x:5555 usb
```

**Scoped-storage on Android 11+ / Chinese ROMs (Xiaomi/HyperOS):** `shell` user (ADB/Shizuku) blocked from `Android/data/<pkg>` — `AdbBackend`/`ShizukuBackend` retry via `run-as <game>` on `Permission denied`; fails if game not debuggable → switch to **SAF** or **Root**. `ConfigManager.pushWithRetry` surfaces same hint.

### Shizuku — Binder IPC

*Best for non-rooted + Shizuku users.* Install [Shizuku](https://shizuku.rikka.app/) → Start service → Select **Shizuku** → **Permit** → **Connect**. `ShizukuBackend` via `ShellUserService` (UserService API, 60s timeout, script-file fallback for >4096 chars, `cp`-based `copyFile`). Requires `-keep class rikka.shizuku.**` (R8) and `ShizukuProvider exported=true` (manifest, intentional).

> **Chinese ROMs:** If `Permission denied` on deploy, enable **both** in Developer Options: **USB debugging** + **USB debugging (Security settings)** (aka *Disable Permission Monitoring*), then re-authorize Shizuku.

### Root — `su -c`

*Best for Magisk/KernelSU/APatch.* Select **Root** → **Test Root** → grant → **Connect**. `RootBackend` (`su -c`, 10s timeout, `cp`-based).

### SAF — Storage Access Framework (No Shell)

*Best for quick one-off edits.* Select **SAF** → **Pick Dir** → navigate to `Android/data/com.kurogame.wutheringwaves.global/files/UE4Game/Client/Client/Saved/Config/Android` → **Allow** (picker pre-targets `primary:Android/data/com.kurogame.wutheringwaves.global` because Android 11+ hides `/Android/data`). `SafBackend` (`DocumentFile`, persistable tree URI, `treeDeviceRoot()` derivation). **No shell** — cannot read logs or run config generator; only push INI via `DocumentFile`.

| Method | Shell | File Push | Log Reading | Config Gen |
|:------:|:-----:|:---------:|:-----------:|:----------:|
| **ADB** | ✅ | ✅ | ✅ | ✅ |
| **Shizuku** | ✅ | ✅ | ✅ | ✅ |
| **Root** | ✅ | ✅ | ✅ | ✅ |
| **SAF** | ❌ | ✅ | Limited | ❌ |

## 🔒 Privacy & Security

- **No telemetry** — `WuWaConfig` sends nothing to third parties. Only `127.0.0.1` ADB + user-initiated `gmserver-api.aki-game2.com/net` (gacha) via `LocalBroadcastManager` (in-process only).
- **At rest:** ADB RSA keys `EncryptedFile` + `AndroidKeyStore` (AES-256-GCM); `allowBackup="false"`; `network_security_config.xml` cleartext only to `127.0.0.1`/`localhost`.
- **Sensitive:** `adb/`, `backend/RootBackend.kt`, `ShizukuBackend.kt`, `SafBackend.kt`, `AdbCrypto.kt`, anything touching `EncryptedFile`/`AndroidKeyStore`. Verify against `.opencode/plans/security_privacy.md` if present.
- **Signing:** `keystore.properties` (gitignored) or env `STORE_PASSWORD`/`KEY_ALIAS`/`KEY_PASSWORD` or `release.jks` (gitignored); `isMinifyEnabled`+`isShrinkResources` only on release; ProGuard keeps `com.wuwaconfig.app.**` + `rikka.shizuku.**`, strips `Log.d/v`; `-keep class rikka.shizuku.**` required (reflection trace).
